# Mini Abarrotes

Sistema web de administración de productos e inventario para una pequeña tienda.

## Tecnologías

- Python
- Flask
- PostgreSQL
- HTML
- CSS
- Git y GitHub

## Funcionalidades actuales

- Panel principal con resumen del inventario.
- Registro de productos.
- Consulta y búsqueda por nombre o categoría.
- Edición de productos.
- Desactivación de productos.
- Validación de precios y existencias.
- Indicador de productos con pocas existencias.

## Requisitos

- Python 3
- PostgreSQL
- Git
